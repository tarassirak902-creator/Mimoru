# Mimoru — матрица возможностей

Документ фиксирует публичную поверхность функций, которую важно сохранять при рефакторинге и проверять автоматическими тестами.

| Раздел | Возможности |
| --- | --- |
| Управление группой | Подключение и отключение группы, диагностика прав, мастер настройки |
| Защита | Антифлуд, ссылки, повторы, капс, капча, карантин, защита редактирования, упоминаний и sender chat |
| Модерация | Предупреждения, мут/размут, бан/разбан, причины наказаний, журнал действий |
| Участники | Поиск, карточка участника, активные ограничения, история, теги и заметки |
| Контент | Запрещённые слова и фразы, приветствие, правила группы |
| Автоматизация | Очистка удалённых аккаунтов, сроки предупреждений, сценарии новичков, журнал автоматизации |
| Аналитика | Статистика группы и активность участников |
| Подписка | FREE, TRIAL, STANDARD, PRO, история платежей и продление |
| Реклама | Глобальные рекламные посты, обязательная подписка, объявления и заявки |
| Поддержка | Создание и просмотр обращений |
| Управление Mimoru | Клиенты, группы, подписки, платежи, реклама, обращения, статистика и служебная рассылка |

## Инварианты интерфейса

- Кнопка «Назад» возвращает на логически предыдущий экран.
- «Отменить ввод» завершает активную форму и возвращает к экрану, из которого форма была открыта.
- Повторное нажатие безопасных кнопок не должно приводить к падению из-за `message is not modified`.
- Старые callback-кнопки, которые ещё могут оставаться в истории Telegram, либо продолжают работать, либо получают безопасный совместимый переход.

## Инварианты эксплуатации

- Секреты не хранятся в репозитории.
- CI публичного репозитория работает на GitHub-hosted runner.
- Деплой выполняет `git pull --ff-only`, проверяет Docker Compose и ждёт healthy-состояния контейнера бота.
- Миграции и preflight выполняются до начала polling.
