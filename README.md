# Mimoru 1.2.0 RC1

Коммерческая платформа управления Telegram-сообществами на русском языке. Один экземпляр обслуживает несколько независимых групп. Управление работает внутри Telegram: русскими командами и кнопочной панелью, без сайта и Mini App.

## Что реализовано

### Панель владельца группы

- «Мои группы» и отдельная карточка каждой подключённой группы;
- статистика выбранной группы за 1, 7 и 30 дней;
- статистика участников и команда `статистика участника` ответом на сообщение;
- настройки антифлуда, ссылок, капчи и приветствия;
- запрещённые слова и обязательные каналы;
- роли модераторов;
- журнал модерации;
- тариф, срок подписки и лимиты;
- рекламная площадка группы и список заказов.

### Панель владельца сервиса

Доступна Telegram ID из `SERVICE_OWNER_IDS`:

- клиенты и заблокированные пользователи;
- все группы и платные группы;
- платежи и сумма Telegram Stars;
- рекламные площадки и заказы;
- обращения поддержки;
- общая статистика сервиса;
- ручная выдача тарифов, промокоды, блокировки и рассылка.

### Модерация и защита

- бан, разбан, мут, размут и предупреждения;
- временные наказания и журнал;
- антифлуд, повторы, ссылки, запрещённые слова и капс;
- ограничения голосовых, стикеров и пересылок;
- капча, карантин новичков и обязательная подписка;
- антирейд, ночной режим и локдаун;
- фильтр массовых упоминаний, координированного спама и сообщений от имени каналов;
- проверка отредактированных сообщений;
- жалобы, автоответы и запланированные публикации.

### Статистика

Статистика хранится отдельно для каждой группы и пользователя:

- количество сообщений;
- количество удалённых сообщений;
- активные участники;
- топ участников;
- статистика конкретного участника;
- ежедневные отчёты.

### Тарифы и подписки

- Free, Standard и Pro;
- пробный период;
- покупка Standard/Pro через Telegram Stars;
- ручная выдача доступа владельцем сервиса;
- промокоды;
- отдельный тариф и срок для каждой группы.

### Рекламный модуль

Владелец группы создаёт площадку командой:

```text
реклама площадка 250 | Описание аудитории, формата и условий
```

Рекламодатель открывает «Купить рекламу», выбирает площадку и создаёт заявку:

```text
заказать рекламу ID_ПЛОЩАДКИ | Текст рекламной публикации
```

Владелец площадки управляет заказом:

```text
принять рекламу ID_ЗАКАЗА
отклонить рекламу ID_ЗАКАЗА
опубликовать рекламу ID_ЗАКАЗА
```

Текущий beta-процесс фиксирует заявку, согласование и публикацию. Автоматическое удержание и распределение оплаты между продавцом и платформой не включено: для этого потребуется отдельная юридическая и платёжная схема.

## Запуск

Потребуются Docker и Docker Compose.

```bash
cp .env.example .env
```

Заполните минимум:

```env
BOT_TOKEN=токен_от_BotFather
SERVICE_OWNER_IDS=ваш_telegram_id
POSTGRES_PASSWORD=сложный_пароль
DATABASE_URL=postgresql+asyncpg://moderator:сложный_пароль@postgres:5432/moderator
REDIS_URL=redis://redis:6379/0
```

Запустите:

```bash
docker compose up --build -d
docker compose logs -f bot
```

Миграции Alembic применяются автоматически.

После запуска:

1. Отключите Privacy Mode в BotFather.
2. Добавьте бота администратором тестовой группы.
3. Дайте права удаления сообщений, ограничений, блокировок и приглашений.
4. Напишите в группе `подключить`.
5. Откройте `/start` в личном чате.

## Честный статус

Это цельная коммерческая beta-сборка, а не готовый к массовой продаже production-релиз. Локальные тесты, компиляция и цепочка миграций проверены. Реальный Telegram polling, платежи и работа под высокой нагрузкой должны быть проверены вами в отдельной тестовой группе и на тестовом VPS до запуска для клиентов.
