# Безопасность

- Никогда не публикуйте `.env` и токен бота.
- Используйте отдельного пользователя PostgreSQL и сложный пароль.
- Ограничьте доступ к VPS по SSH-ключам.
- Регулярно проверяйте резервные копии восстановлением на тестовой базе.
- При утечке токена немедленно перевыпустите его через BotFather.
- `SERVICE_OWNER_IDS` должен содержать только доверенные Telegram ID.
